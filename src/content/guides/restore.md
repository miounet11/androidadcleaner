工具做的每件事都能还原。下面按类别列出方法，建议从你改动最多的那一类开始。

## 一条命令全部还原

```bash
python3 tool/run.py -s <序列号> restore --all
```

需要之前执行过 `backup`。还原会读快照，只恢复快照里记录过的项目。

## 分类还原

### 1. 挂起的系统广告包

```bash
python3 tool/run.py -s <序列号> restore --packages
```

等价于对每个记录过的包执行：

```bash
adb shell pm unsuspend <包名>
```

没有快照时，查看当前挂起的包：

```bash
adb shell pm list packages -d
```

然后对你要恢复的包逐个 `pm unsuspend`。

### 2. 通知渠道

```bash
python3 tool/run.py -s <序列号> restore --channels
```

把营销渠道恢复为改动前的状态。也可以在系统的「设置 → 应用 → 某应用 → 通知」里手动打开。

### 3. 快应用

```bash
python3 tool/run.py -s <序列号> restore --quickapp
```

### 4. App 内的开关

这部分系统没有读取接口，快照里只能记录「应该是开」，需要手动点回去。原路在[手动清单](/guides/manual-checklist)里，每一步都写了位置。

最常需要还原的几个：

| 项目 | 位置 |
|---|---|
| 应用商店个性化推荐 | 应用商店 → 我的 → 设置 |
| 浏览器个性化内容 | 浏览器 → 我的 → 设置 → 隐私 |
| 负一屏推荐卡片 | 桌面左滑 → 设置 |
| 全局搜索热榜 | 搜索页 → 设置 |

## 完全重置

如果手机状态混乱、想从零开始：

1. 先跑 `restore --all`；
2. 重启手机；
3. 重新跑 `check` 确认状态。

不建议用「恢复出厂设置」来解决 —— 那是为了几个开关付出太大的代价。

## 常见问题

**还原后广告没回来**：部分广告是服务端推送的，关掉后再开需要等下次推送周期。也可能缓存还在，重启手机再看。

**不记得改过什么**：看快照目录下的 JSON，里面记录了每一次改动的包名与渠道 id。

**换手机了，旧快照能用吗**：不能跨设备使用。快照与型号、构建号绑定，换了设备请在新设备上重新备份。

## 关于「不可逆」的说明

工具里没有不可逆操作。它不使用 `pm uninstall`、不改 system 分区、不写 Bootloader。唯一需要手动找回的是 App 内的设置项，因为系统不提供读取接口。

如果你发现某个改动找不到还原方法，这是文档缺失，请[提 issue](/guides/report-issue) 告知。
