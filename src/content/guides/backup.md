备份是唯一一个"看起来多余、实际最省事"的步骤。跑一次几十秒，能省掉一次重装系统的念头。

## 执行

```bash
python3 tool/run.py -s <序列号> backup
```

客户端里对应的是「检测」之后出现的「保存快照」按钮。

## 快照里存了什么

| 内容 | 用途 |
|---|---|
| 已挂起的系统包列表 | 还原时逐个 `pm unsuspend` |
| 各 App 的通知渠道状态 | 还原营销渠道的开启/关闭 |
| 关键设置项读数 | 部分系统设置无法脚本还原，提供数值供手动恢复 |
| 型号、构建号、时间 | 判断快照适用于哪台机器哪个版本 |

快照保存在数据目录的 `snapshots/` 下，文件名带时间戳。

## 快照不等于系统备份

它不备份照片、聊天记录、应用数据。它只记录**这个工具会改动的那部分状态**。系统更新、恢复出厂这类操作不在覆盖范围。

## 还原

```bash
python3 tool/run.py -s <序列号> restore
```

还原只处理快照里记录过的项目：挂起的包恢复运行，通知渠道回到原状态。工具没动过的开关不会被动。

App 内的设置项（比如浏览器里的「个性化推荐」）系统不提供读取接口，快照里记的是「原本应该是开」，需要按清单路径手动打开。指南里每一项都写了原路。

## 什么时候必须备份

- 第一次在一台新机器上跑；
- 系统大版本更新后；
- 借别人的手机操作的时候。

## 快照的问题排查

**还原后还有广告**：先确认是不是营销推送渠道。渠道还原是精确到单个 channel 的，某些 App 更新后会新建渠道，这些新渠道在旧快照里没有记录。

**快照文件丢失**：快照只存在本地电脑上，不在云端。换电脑后需要重新备份。
