去广告的所有操作都通过 adb 完成，第一步是把手机的调试通道打开。这一步每家厂商的入口名字略有不同，但结构一样。

## 通用步骤

1. 打开 **设置 → 关于手机**（部分系统叫「我的设备」「关于设备」）。
2. 找到 **版本号**，连续点击 7 次。系统会提示「你已处于开发者模式」。
3. 返回设置，进入 **系统设置 → 开发者选项**（部分系统直接在设置底部）。
4. 打开 **USB 调试**。
5. 用数据线连接电脑，手机弹出「允许 USB 调试吗？」时勾选 **一律允许使用这台计算机进行调试**，点确定。

> 如果第 5 步的弹窗一直不出现，先换一根支持数据传输的线。很多随手机附送的线只供电、不传数据。

## 各品牌的额外开关

部分系统在「USB 调试」之外还有一层限制，不打开的话脚本能读到页面但点不动。

| 品牌 | 需要额外打开 | 位置 |
|---|---|---|
| 小米 / Redmi / POCO | USB 调试（安全设置） | 开发者选项 → 需登录小米账号 |
| OPPO / 一加 / realme | 禁止权限监控（关闭它） | 开发者选项 → 底部 |
| vivo / iQOO | USB 调试（安全设置） | 开发者选项 |
| 荣耀 / 华为 | 仅充电模式下允许 ADB 调试（打开） | 开发者选项 |

小米的「USB 调试（安全设置）」需要登录小米账号并联网验证，这是系统限制，不是工具的问题。

## 无线调试（Android 11 以上）

不想插线可以用无线调试：

1. 手机和电脑连同一个 Wi-Fi。
2. 开发者选项 → **无线调试** → 打开。
3. 点「使用配对码配对设备」，记下配对码和端口。
4. 在电脑上执行：

```bash
adb pair 手机IP:配对端口
adb connect 手机IP:调试端口
```

配对码只在配对时用一次。手机重启后需要重新配对。

## 用完之后

改动完成、确认没问题后，回到开发者选项把 **USB 调试** 关掉。开着调试通道会让任何连上这台手机的人都能读取屏幕内容，日常使用建议关闭。

命令行方式关闭（最后一步，执行后立即断开）：

```bash
python3 tool/run.py -s <序列号> dev-off --yes
```

## 常见问题

**找不到「开发者选项」**：说明版本号没点够 7 次，或者点错了位置。要连续、快速地点，看到倒计时提示就说明点对了。

**弹窗点了确定但电脑仍显示未授权**：拔掉数据线重插，或在开发者选项里点「撤销 USB 调试授权」后重连。

**公司或学校发的手机连不上**：部分 MDM 管理的设备会禁用 adb，这种情况无法绕过，也不建议绕过。
