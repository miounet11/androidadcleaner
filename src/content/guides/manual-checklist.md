不想连电脑也能关掉大部分系统广告。下面按品牌列出逐项路径，照着点即可。每一项都是系统自带的开关，不涉及任何修改。

建议顺序：先关总开关，再关各 App 的子项。总开关关掉后有些子项会消失，这是正常的。

## 小米 / Redmi / POCO（HyperOS）

1. **系统广告服务**：设置 → 隐私与安全 → 更多安全设置 → 广告服务 → 关闭「个性化广告推荐」，打开「限制广告跟踪」。
2. **应用商店**：应用商店 → 我的 → 右上齿轮 → 关闭「个性化服务」；「模式切换」改成极简；关闭「新手帮助」。
3. **手机管家**：手机管家 → 右上齿轮 → 关闭「个性化推荐」「垃圾清理推荐内容」。
4. **下载管理**：下载管理 → 更多 → 设置 → 信息流设置 → 关闭「资源推荐」「热榜推荐」。
5. **主题**：主题 → 我的 → 右上齿轮 → 关闭「每次联网通知」「个性化推荐」。
6. **浏览器**：浏览器 → 我的 → 齿轮 → 隐私和安全 → 关闭「个性化内容推荐」「个性化广告推荐」。
7. **全局搜索**：桌面下滑 → 搜索页右上齿轮 → 关闭「搜索提示词」「应用推荐」「热搜榜单」。
8. **负一屏**：桌面左滑 → 设置 → 关闭「推荐卡片」「热门活动」「个性化推荐」。
9. **天气 / 日历**：天气、日历 → 设置 → 用户体验计划 → 关闭内容推广与个性化推荐，**保留天气预警**。

> 注意：「限制广告跟踪」这类开关是「打开=保护」，和其它开关方向相反，不要顺手关掉。

## OPPO / 一加 / realme（ColorOS / realme UI）

1. **广告跟踪**：设置 → 隐私 → 设备标识与广告 → 广告跟踪 → 逐个关闭。没有总开关，新装 App 后需要回来再关。
2. **负一屏**：桌面左滑 → 左上头像 → 设置 → 关闭「搜索框提示词」「轮播推荐」「热点资讯」。
   **不要关「推荐服务」总开关** —— 会连带把天气、步数、清理卡片一起删掉。
3. **下拉搜索**：桌面中间下滑 → 搜索页设置 → 关闭「热搜」「推荐卡片」「个性化推荐」。
4. **软件商店**：软件商店 → 我的 → 设置 → 服务管理 → 关闭轮播、开屏、悬浮活动、签到福利。
5. **浏览器**：浏览器 → 我的 → 设置 → 关闭资讯推荐、个性化内容。

## vivo / iQOO（OriginOS）

1. **广告与隐私**：设置 → 安全 → 更多安全设置 → 广告与隐私 → 关闭「个性化广告」「个性化推荐」「智能推荐服务」。
2. **负一屏**：桌面左滑 → 右上齿轮 → 更多设置 → 个性化推荐 → 关闭服务推荐、资讯推荐、内容精选、热点资讯。
3. **全局搜索**：设置 → 系统管理与升级 → 全局搜索 → 关闭搜索框推荐词、推荐卡片、热门搜索、广告个性化。
4. **快应用**：见[快应用是什么](/guides/quickapp)。

> 负一屏里的「便捷生活推荐服务」不要关：扫码、手电筒、计算器那 10 个图标靠它补位，关掉整块会变空。

## 荣耀（MagicOS）

1. **广告与隐私**：设置 → 搜索「广告」→ 广告与隐私 → 右上 ⋮ → **显示系统程序** → 全部关闭；同时关闭「智能推荐服务」。
2. **YOYO 建议**：设置 → 搜索「新闻资讯」→ 关闭新闻资讯。
3. **下拉搜索**：桌面下滑 → 更多 → 设置 → 关闭热搜榜、热搜词推荐、个性化管理。
4. **负一屏**：桌面左滑 → 头像 → 设置 → 关闭推荐卡片与资讯。

> 「显示系统程序」这一步容易漏。默认列表只显示你自己装的应用，系统应用的广告标识读取开关藏在切换之后。

## 华为（HarmonyOS 4）

1. **广告与隐私**：设置 → 隐私 → 广告与隐私 → 关闭「个性化广告」「智能推荐服务」。
2. **应用市场**：应用市场 → 我的 → 设置 → 关闭个性化推荐、内容推荐。
3. **浏览器**：浏览器 → 我的 → 设置 → 关闭资讯推荐、个性化内容。

> HarmonyOS NEXT（5.0 起）没有这些开关路径，也不支持 adb，本工具无法处理。

## 三星（One UI）

1. **自定义服务**：设置 → 隐私 → 自定义服务 → 关闭个性化推荐与营销信息。
2. **三星应用商店**：应用商店 → 菜单 → 设置 → 关闭个性化推荐、促销通知。
3. **三星浏览器**：浏览器 → 设置 → 隐私 → 关闭个性化内容与广告。

> 国行机型广告入口比港版多，操作前先确认版本。

## 手动关完之后

有两类东西手动关不掉，需要用 adb：

- **通知渠道级关闭**：营销推送和订单通知同一个 App，只能在渠道层面区分；
- **系统广告组件挂起**：`com.miui.systemAdSolution` 这类包没有界面开关。

这两项需要连电脑，见[通知渠道与营销推送](/guides/channel-push)和[系统广告组件](/guides/system-ad-package)。
